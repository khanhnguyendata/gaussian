Gaussian sampling from the inverse CDF

Inspired by the explorations in notebooks/part1.ipynb, this web app turns the Taylor-series approximation of the inverse error function into an interactive playground. Sample uniform areas, push them through a tunable inverse CDF, and inspect how closely the resulting Gaussian points follow the target distribution.

Use the controls below to tweak:

  • How many samples are drawn from U(0, 1)
  • Which Taylor degree powers the inverse CDF
  • Independent seeds for the X/Y streams

Higher degrees hug the true inverse CDF but cost more arithmetic.
